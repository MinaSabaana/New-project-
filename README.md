# New-project-
Building AI project 
FörståMig AI
Final project for the Building AI course

## Summary

FörståMig AI is an AI tool that helps people understand information from public authorities. It explains difficult texts in simple language, summarizes important information, explains difficult words, finds important dates, and helps users understand what they need to do.


## Background
Communication from public authorities can sometimes be difficult to understand. Official letters may contain formal language, complicated terms and long explanations. For some people, this can make it difficult to understand what a decision means or what they are expected to do next.

This can be particularly challenging for people who have Swedish as a second language, people with limited experience of communicating with authorities, or people who find complex written information difficult to understand.

The problem is important because understanding information from public authorities can affect people's ability to manage their own affairs and respond correctly to important requests or decisions.

My idea is to create an AI tool that makes this information easier to understand without changing the original decision or giving legal advice.

How is it used?
The user can use FörståMig AI when they receive a letter, decision or other information from a public authority that they find difficult to understand.

First, the user uploads a document or copies and pastes the text into the tool. The AI then reads and analyzes the text.

The AI gives the user a simpler explanation of the information. It can also find important dates, explain difficult words and show what the user may need to do.

The information can be presented in different sections:

What is this about?
What do I need to do?
Important dates
Difficult words
Questions

The user can also ask questions about the text. For example, the user could ask:

"What documents do I need to send?"

The AI would then explain the answer in simple language.

The project would mainly use information that is already available from public authorities. Examples could be public information, official terms, explanations and examples of authority language.

The user would also provide data by uploading a letter or copying text into the tool. This information would only be used to understand and explain the text.

##Challenges

The project cannot solve every problem connected to communication with public authorities.

The biggest challenge is that AI can make mistakes. The AI can misunderstand a sentence or leave out important information when it simplifies a text.

This can be especially serious when the information is about laws, money, applications or deadlines.

FörståMig AI should therefore not make decisions for the user or give legal advice. It should only help the user understand information that already exists.

Privacy is another important challenge. Authority letters can contain personal and sensitive information. The system must therefore protect the user's information.

There is also a risk that users trust the AI too much. The user should always be able to see the original document and understand that the AI explanation can contain mistakes.

Other challenges include:

protecting personal information
keeping the original meaning of the text
supporting different languages correctly
making the tool accessible to different users
making sure important information is not removed
making the AI explanation clear but not misleading.
For these reasons, human control is important. The AI should support people, not replace people or official decisions.

What next?
I would like to develop FörståMig AI further in the future.

One possible development is to support more languages. The tool could also read the information aloud for people who prefer listening instead of reading.

Another idea is to create a simple checklist based on the information in the document.

For example:

☐ Send the requested document
☐ Add the required information
☐ Contact the authority if something is unclear
☐ Remember the deadline

The AI could also help users write questions to the public authority. In the future, the tool could possibly be connected to public authority websites.

Before using the tool in real situations, it would be important to test it with different users. I would like to find out if people actually understand the information better after using the tool.

To develop the project, I would need help from people with knowledge about AI, programming, public administration, language, accessibility and privacy.

I would also need to learn more about how to build and test an AI system and how to protect personal information.

My long-term goal would be to create a simple and safe tool that helps more people understand information from public authorities.
